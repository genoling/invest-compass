# 2026-07-26 开发日志

## 项目启动：智投罗盘 InvestCompass

###架构决策
- **前端框架**：React 18 + Vite（而非 Next.js），原因：SPA 足够满足需求，Firebase 中心化架构，Vite HMR 更快
- **数据库**：Firestore（而非 Realtime Database），原因：查询能力更强，适合资讯筛选/知识检索
- **无需用户认证**：个人使用，移除 Firebase Authentication 模块
- **支付模块延后**：Stripe 非 MVP 核心，后续迭代
