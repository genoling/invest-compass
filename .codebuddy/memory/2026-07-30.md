## 关键经验教训

### 目录重构的陷阱（v2 重要发现）
把配置文件移到 `config/` 子目录后，Tailwind CSS 失效。

**根因：** Vite 的 `root` 指向项目根目录，PostCSS 默认从 `root` 目录查找 `postcss.config.*`，找不到则跳过 Tailwind 处理。

**修复：** 在 `vite.config.ts` 显式配置 PostCSS 插件：
```ts
import tailwindcss from "tailwindcss";
import autoprefixer from "autoprefixer";

css: {
  postcss: {
    plugins: [tailwindcss({ config: TAILWIND_CONFIG }), autoprefixer()],
  },
}
```

**Tailwind content 路径规则：** 使用 `./index.html` 和 `./src/**/*.{ts,tsx}`，因为 Vite 的 cwd 始终是项目根目录。
