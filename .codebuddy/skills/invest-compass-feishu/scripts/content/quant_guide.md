# 量化模型使用指南

> 智投罗盘量化模块（/quant）使用说明：创建策略、回测验证、量化操作

---

## 一、核心概念：策略（Strategy）

**策略** = 一套可执行的交易规则集合。系统提供 4 种预设模板，本质是「什么条件触发买入、什么条件触发卖出」的数学化描述。

**用法**：点击「新建策略」→ 选择模板 → 配置参数 → 创建后在列表启停

---

## 二、策略模板详解

### ① 均线交叉策略（MA Cross）

- **含义**：基于短期与长期均线的交叉判断趋势转向
- **参数**：`shortPeriod`（短期均线周期）、`longPeriod`（长期均线周期）
- **用法**：短期均线上穿长期均线（金叉）→ 买入；下穿（死叉）→ 卖出
- **适用**：趋势行情

### ② 动量突破策略（Momentum）

- **含义**：假设价格突破前高后延续上涨（动量效应）
- **参数**：`lookbackPeriod`（回看周期）、`breakoutThreshold`（突破阈值，如 1.02 = 突破前高 2%）
- **用法**：价格突破 N 日高点 × 阈值 → 买入；跌破 N 日低点 → 卖出
- **适用**：单边行情

### ③ 均值回归策略（Mean Reversion）

- **含义**：假设价格偏离长期均值后会回归（物极必反）
- **参数**：`meanPeriod`（均值周期）、`deviationThreshold`（偏离倍数，如 2 = 偏离 2 个标准差）
- **用法**：价格低于均值-2σ（超跌）→ 买入；回归均值 → 卖出
- **适用**：震荡行情

### ④ 网格交易策略（Grid Trading）

- **含义**：在预设价格区间内分层挂单，每层低买高卖赚差价
- **参数**：`gridLevels`（网格层数）、`upperPrice`（上沿）、`lowerPrice`（下沿）
- **用法**：价格在区间内波动时自动高抛低吸
- **适用**：震荡市

## 三、回测参数术语

| 参数 | 说明 |
|------|------|
| 策略 | 选择要验证的已创建策略 |
| 标的代码 | 证券代码，如 `000001.SZ`、`600519.SH` |
| 起始/结束日期 | 回测历史区间，尽量覆盖牛熊周期 |
| 初始资金 | 模拟起始本金 |
| 开始回测 | 执行回测（当前为模拟演示） |

---

## 四、回测指标术语

- **总收益率**（Total Return）：期末相对期初总涨跌幅，越高越好
- **年化收益率**（Annual Return）：折算到每年的收益，便于跨周期比较
- **最大回撤**（Max Drawdown）：历史高点回落最大幅度，衡量风险，越低越好
- **夏普比率**（Sharpe Ratio）：每承担 1 单位风险获得的超额收益，>1 良好，>2 优秀
- **胜率**（Win Rate）：盈利交易占比，高胜率≠高收益（需结合盈亏比）
- **总交易次数**：回测期间触发信号总次数
- **平均持仓天数**：每笔平均持有时间，反映换手频率

---

## 五、权益曲线与交易记录

- **权益曲线**（Equity Curve）：账户总价值走势图，展示策略成长与波动
- **交易记录**（Trade Log）：每笔买卖的日期、价格、数量、金额与触发原因，用于复盘

---

## 六、使用建议

1. 先用不同周期（短/中/长）做多组回测，观察指标稳定性
2. 关注 **最大回撤** —— 即使收益高，回撤过大会导致中途割肉
3. 结合 **夏普比率** 与 **胜率** 综合判断，避免只看单一指标
4. 回测是历史模拟，**不保证未来表现**，实盘需谨慎
