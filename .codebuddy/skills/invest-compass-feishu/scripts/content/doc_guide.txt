智投罗盘 - 飞书文档目录使用说明

本文档说明智投罗盘项目飞书目录的结构、各文档的用途及如何配合开发使用。

一、项目目录结构

项目文件夹下共 7 个子目录 + 3 个根级文档：

01_需求管理
02_项目管理
03_设计文档
04_开发管理
05_测试管理
06_上线部署
07_项目资产

根级文档：想法草稿、智投罗盘草案、产品需求规格说明书

二、各目录用途详解

【01_需求管理】
用于管理产品的需求、缺陷和迭代规划。
- 产品需求规格说明书：产品总纲，描述功能模块、技术栈、待办规划（开发时需随代码同步更新）
- 需求矩阵表：功能-模块-优先级对应关系
- 核心业务流程图：业务流程可视化
- 需求变更记录表：记录需求变更历史

【02_项目管理】
用于项目进度与里程碑管理。
- 项目总体开发计划：3 个月分阶段规划
- 迭代任务清单：按周更新任务进度
- 风险评估与应对方案：识别风险并制定应对
- 项目里程碑与验收标准：阶段验收准则

【03_设计文档】
用于记录技术设计方案。
- 产品概要设计说明书：系统架构设计
- 数据库设计说明书（Firebase）：数据模型设计
- 接口设计说明书：第三方 API + 内部数据结构
- UI交互设计规范：界面与交互标准
- 核心业务逻辑设计：投资理念编码 + AI 分析规则

【04_开发管理】
用于开发过程中的技术手册。
- 开发环境搭建指南：本地环境配置
- 第三方服务集成手册：Firebase/金融API/AI/支付
- 模块开发技术设计：按模块拆分的技术方案
- 代码规范与提交约定：Conventional Commits + 构建门禁
- 常见问题排查手册：常见错误与解决方案

【05_测试管理】
用于测试与缺陷跟踪。
- 测试用例总表：功能测试用例
- Bug跟踪记录表：Bug 登记与状态管理（多维表格）
- 功能/安全/性能测试报告：各阶段测试结果

【06_上线部署】
用于部署与运维。
- 生产环境部署方案：上线流程
- 域名与SSL配置指南
- 上线验证检查清单
- 生产环境运维手册

【07_项目资产】
用于存放项目资产与敏感信息（脱敏）。
- 项目Logo与视觉素材
- 环境变量配置清单（脱敏版）
- 账号与密钥管理表（脱敏版）

三、开发协同规则

1. 修改功能模块代码时，必须同步更新「产品需求规格说明书」对应章节 + README.md
2. 记录新需求或 Bug，用「整理想法」从草稿提取，或直接说"记个需求/提个bug"
3. Bug 跟踪使用多维表格（需求管理表 + Bug跟踪表）
4. 文档更新脚本位于 .codebuddy/skills/invest-compass-feishu/scripts/

四、常用操作速查

- 创建文档：python create_named_doc.py <文件夹token> <标题> <内容文件>
- 整理想法：说"整理想法" 或 python draft_to_bitable.py <草稿ID>
- 记录需求：说"记个需求 xxx"
- 记录Bug：说"提个bug xxx"
