# 智投罗盘 - 产品需求规格说明书

> **InvestCompass** — AI 辅助的个人投资决策与资产管理平台

---

## 一、项目概述

**智投罗盘**是一套聚焦个人投资理念落地、覆盖 **行情获取 → 目标执行 → 决策辅助 → 知识支撑** 完整闭环的轻量级投资决策与资产管理 MVP。

核心目标：将用户的投资理念转化为产品可执行的逻辑，提供从目标设定到操作建议的全流程支持。

---

## 二、功能模块

### 2.1 实时资讯
- **行情跑马灯**：8 个品种，3 秒自动刷新
- **分类/关键词筛选** + 无限滚动
- **K 线图**：支持 1min / 5min / 15min 维度切换
- 数据源：Mock（当前）→ AKShare（计划中）

### 2.2 投资目标管理
- **目标创建**：短/中/长期，保守/稳健/激进
- **持仓管理** + 进度追踪 + 再平衡建议 + 操作历史
- React Hook Form + Zod 校验

### 2.3 量化模型
- **策略管理**：均线交叉 / 动量突破 / 均值回归 / 网格交易 4 种模板
- **回测引擎**：当前 Mock 回测 → 计划接入 AKShare 真实 A股历史数据
- **模拟交易引擎**（开发中）：自建模拟账户 + A股交易规则
- **实盘交易**（规划中）：同花顺模拟盘 → 中信证券 QMT
- 详见 → `04_开发管理/量化模型使用指南` + `03_设计文档/核心业务逻辑设计`

### 2.4 AI 辅助决策
- **四维度分析**：市场情绪 / 技术面 / 基本面 / 风险
- **操作建议**：买入 / 卖出 / 持有
- 参数控制 + 结果复制

### 2.5 知识学习
- **6 大分类**：投资理念 / 基础术语 / 技术分析 / 基本面 / 风险控制 / 策略案例
- 难度筛选 + 搜索 + 进度统计 + 全文阅读

---

## 三、技术栈

- **前端**：React 18 + TypeScript + Vite + Tailwind CSS 3.x + Recharts + React Hook Form + Zod
- **后端**：Firebase（Firestore / Cloud Functions / Hosting / AI Logic）
- **行情数据**：AKShare（A股，免费开源）+ Python Flask 桥接
- **模拟交易**：自建引擎（A股 T+1/涨跌停/100股起）
- **实盘交易**：同花顺模拟盘（调研中）→ 中信证券 QMT（规划中）
